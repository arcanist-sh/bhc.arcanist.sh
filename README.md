# bhc.arcanist.sh (retired)

This was the website for [bhc](https://github.com/arcanist-sh/bhc), the Basel Haskell Compiler.
It has moved:

- **Product page, status, profiles, targets, roadmap, playground and blog:**
  [arcanist.sh/bhc](https://arcanist.sh/bhc/), built from `content/bhc/` in the arcanist.sh website
  repository
- **Documentation and the standard library API reference:** [docs.arcanist.sh/bhc](https://docs.arcanist.sh/bhc/),
  built from [bhc.arcanist.sh-docs](https://github.com/arcanist-sh/bhc.arcanist.sh-docs)
- **Install script:** [arcanist.sh/bhc/install.sh](https://arcanist.sh/bhc/install.sh)
- **The design:** this site's look lives on as the Zola theme
  [brutalist-blueprint](https://github.com/arcanist-sh/brutalist-blueprint)

The pages this repository served under arcanist.sh/bhc that no longer exist there
(`/bhc/get-started/`, `/bhc/compiler/`, `/bhc/about/`, `/bhc/docs/api/`) redirect to their new homes.
Nothing here is built or deployed any more; the history is kept for reference.
